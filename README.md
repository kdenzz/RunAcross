# Run Across

A neon platformer-puzzler built in Unity 6 (URP). This repo is the rebuild. The first milestone is a look-dev scene that brings the in-game graphics up to the style of the original Blender render.

## Layout

```
Art/Source/SF.blend        source scene (Blender 4.5, Git LFS)
Tools/export_fbx.py        headless Blender export -> Unity
RunAcross/                 Unity 6000.6.5f1 project (URP)
  Assets/_Project/
    Art/Models             Environment.fbx, Courier.fbx (generated)
    Art/Textures           unpacked + baked maps (generated)
    Art/Materials          URP materials (generated by the builder)
    Editor/LookDevSceneBuilder.cs   rebuilds the scene; all look values live here
    Scenes/LookDev_Neon.unity
    Scripts/Rendering/PlanarReflection.cs   mirror reflections for the wet floor
    Scripts/Player/PlayerMotor.cs           walk / sprint / jump
    Scripts/CameraRig/CameraModeToggle.cs   Tab: look-dev shot <-> third-person
    Shaders/NeonWater.shader, GradientSky.shader
```

## Art pipeline

1. Edit `Art/Source/SF.blend` in Blender.
2. Export:
   ```sh
   /Applications/Blender.app/Contents/MacOS/Blender -b Art/Source/SF.blend -P Tools/export_fbx.py
   ```
   This writes the FBX files and textures. It also bakes the floor's procedural bump into a normal map and a smoothness map, and packs the glTF metal/roughness maps into Unity's MetallicSmoothness format.
3. In Unity, run **RunAcross > Build Look-Dev Scene**. It rebuilds the materials, the model import settings and the scene.

## How the look is made

- **Emissives**: HDR emission with ACES tonemapping and bloom (threshold 0.9, scatter 0.8). The hot cores turn yellow and the edges stay orange.
- **Wet floor**: `PlanarReflection` renders a mirrored camera into an HDR texture, so the neon reflections still bloom. `NeonWater` samples it with ripple distortion and fresnel. URP has no screen-space reflections.
- **Atmosphere**: exponential fog matched to the horizon colour of the gradient skybox, a dark blue sun, and trilight ambient.
- **Lens**: bokeh depth of field focused at 11.5 m, plus vignette and fine film grain.
- **Building windows**: Blender lights them with a red area light, and URP area lights are bake-only. Emissive panes stand in for it, plus a point light that spills the colour onto the floor.

## Controls

WASD / left stick to move, Shift to sprint, Space to jump, mouse / right stick to orbit the camera, Tab to switch to the look-dev camera.
